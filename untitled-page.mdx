This section describes the RegattaDB SQL specification for vector indexing. 

The RegattaDB specification follows the style of the _pgvector_ extension of PostgreSQL. As in other parts of the SQL specification, there are deviations from PostgreSQL where needed to support RegattaDB’s performance and functionality. 

This is a first and early release of the vector index and the approximate vector search feature. It contains the basic functionality required for AI applications to perform approximate vector searches. Additional improvements will be added in future releases.
