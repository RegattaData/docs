title: "Date/Time Functions and Operators"
---

The following tables show the Date/Time operators that are available for the `DATE/TIME/TIMESTAMP` datatypes. See [Date/Time types](/sql/data-types/date-time-types).

All the following operators and functions return their values without a time zone.

### Date/Time Functions

| Function | Description and Comments | Example |
| :-- | :-- | :-- |
| `CURRENT_DATE` | Return the date on which the current transaction started. | `SELECT CURRENT_DATE;`<br />`=> 2012-03-26` |
| `CURRENT_TIME` | Return the time in which the current transaction started. | `SELECT CURRENT_TIME;`<br />`=> 11:31:46.903633` |
| `CURRENT_TIMESTAMP` | Return the timestamp in which the current transaction started. | `SELECT CURRENT_TIMESTAMP;`<br />`=> 2012-03-26 11:31:46.903633` |
| `NOW()` | Return the timestamp in which the current transaction started.<br />Same as `CURRENT_TIMESTAMP`. | `SELECT NOW();`<br />`=> 2012-03-26 11:31:46.903633` |
| `EXTRACT(unit FROM object)` | Extracts the specified unit (date or time part) from a date, time, or timestamp<br />Returns `DECIMAL`<br />See notes below. | `SELECT EXTRACT(YEAR FROM '2012-03-26 11:31:46.903633'::TIMESTAMP );`<br />`=> 2012`<br /><br />`SELECT EXTRACT('day' FROM '2012-03-26'::DATE);`<br />`=> 26` |
| `DATE_PART(unit, object)` | Similar to `EXTRACT()`<br />Returns `DECIMAL`<br />See notes below. | `SELECT DATE_PART('day', TIMESTAMP '2012-03-26 11:31:46.903633');`<br />`=> 26`<br /><br />`SELECT DATE_PART('minute', TIME '11:31:46.903633');`<br />`=> 31` |

Note: `DATE_PART()` and `EXTRACT()` provide similar functionality and accept the same set of units. However, `DATE_PART()` requires the unit argument to be passed as a string (e.g. 'YEAR', 'day'), while `EXTRACT()` also accepts these units as keywords.

The following units are supported for `TIME` objects:  hour, minute, second, milliseconds, microseconds.

The following units are supported for `DATE` objects: millennium, century, decade, year, quarter, month, week (indicates the week number in the year), day (indicates the day number in the month).

For `TIMESTAMP` objects, both the date and time units are supported.
