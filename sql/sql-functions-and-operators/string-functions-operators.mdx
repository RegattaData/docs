title: "String Functions and Operators"
---

This following table describes the functions and operators for examining and manipulating string values (`CHAR` and `VARCHAR` data types). See [Character types](/sql/data-types/character-types).

Except where noted, these functions and operators are declared to accept and return type `VARCHAR`.

Notes:

1. Text comparison is case-sensitive (e.g, ‘Regatta’ `<>` ’REGATTA’ `<>` ‘regatta’ and 'A' \< 'B' \< 'a' \< 'b').
2. Values of type `CHAR` are converted to `VARCHAR` before the function or operator is applied, resulting in stripping any trailing spaces in the character value.

Notes:

1. The string concatenation operator (||) accepts non-string input, so long as at least one input is of string type. Using the operator with `NULL` as one of the operator inputs, returns NULL. For example: `SELECT 'Hello' || NULL || ' this is me';` Return: `NULL`
2. `CONCAT():`
   - All values are implicitly converted to strings
   - `NULL` arguments are ignored. For example: `SELECT CONCAT('Hello', NULL, ' this is me');` Return: 'Hello this is me'
3. `SUBSTRING(string, start [, count])` receives start position and optional count. If count is omitted, the extracted substring is until the end of the input string.<br />`SUBSTRING(string [FROM start] [FOR count])` – both FROM and FOR are optional but at least one of them should be included. If FROM is omitted, start from the beginning of the input string. If `FOR count` is omitted, extract until the end of the input string.<br />If the FROM argument is less than 1, the returned substring begins from position 1 but the difference is subtracted from the count. For example, `SELECT SUBSTRING(‘hello’, FROM -1 FOR 3)` returns `‘h’`.
4. TRIM() – In the first form, ‘FROM’ is mandatory if `trim_chars` is included and optional otherwise. In the second form it’s optional.
3. `LPAD()` (`RPAD()`): If the input string is longer than the requested `length_int` then it is truncated on the right (left).
4. `LIKE` and `NOT LIKE`:
   1. String match is case sensitive
   2. Escape character should be a single character.
   3. Possible patterns:
      - An underscore (\_): stands for any single character
      - A percent sign (%) stands for any sequence of zero or more characters
      - If the pattern does not contain percent signs (%) or underscores (\_), it a simple string comparison.
