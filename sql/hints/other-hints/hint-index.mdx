---
title: Hint - INDEX
---

### Synopsis

```text
[ INCLUDE ] INDEX (table_name, { index_list [, EXCLUSIVE ] | ALL } )

EXCLUDE INDEX (table_name, { index_list | ALL } )

where index_list is:
  ( index_entry [, ...] )

and index_entry is:
 { index_name | COLUMN column_name }
```

The index hints affect the use of indexes to evaluate a query. A hint comment may contain at most one `INCLUDE INDEX` and at most one `EXCLUDE INDEX` hint per table. The hints instruct the query optimizer which indexes to use or not to use for the query.

A single-column index can be referenced either by its name or by the column’s name. A multi-column index must be referenced by its name.

### Parameters

#### `ALL`

All the indexes of the table should be used if applicable for the statement.

#### `EXCLUSIVE` 

Any index not listed in the **_index_list_** must not be used.

Included indexes _shall_ be used where applicable. Excluded indexes _shall not_ be used. Other indexes _may_ be used. For example, in the following query:

```sql
SELECT /*++ INCLUDE INDEX(t, (COLUMN a)) */ a, b FROM t WHERE b = 8;
```

an index on column `a` will not be used because it’s not applicable for the statement, and an index on column `b` may be used. (You can use `EXPLAIN` to check what indexes would be used.)

### Examples

```sql
SELECT /*++ INDEX(o, COLUMN deptno), INDEX(s, ALL) */
s.name, o.id
FROM staff s JOIN org o
ON s.deptno = o.deptno
WHERE o.division = 'EASTERN';
```
